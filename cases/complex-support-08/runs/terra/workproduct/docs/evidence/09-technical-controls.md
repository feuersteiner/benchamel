# E09 — Restricted view and export engineering readiness

Record version: ENG-482.3. Owner: access engineer Tomas Hale. Snapshot: 2026-11-12 11:50 UTC. Status: technical capability report, not proof that all gates have passed.

Restricted view is a dedicated gateway mode. It permits named challenged administrators to read Dispatch assignment rows and audit selected changes. It disables creation of signed links, package download, integration jobs, publication and role changes. It cannot send contractor assignments automatically. Dispatchers would need to transcribe or manually distribute the limited information through their own approved channel. An ordinary read-only role differs from this mode because ordinary read-only accounts can follow existing package links. The distinction is consequential for both customer explanation and execution.

The scope test for the gateway configuration passed at 11:30. Research identifiers returned denied in all tested paths. The test used a synthetic account with the same gateway rule shape and a read-only snapshot of Lattice's workspace mapping; it did not use live customer credentials. Security must still confirm credential revocation and live scope checks before activation. A passed test shows expected configuration behavior, not that Lattice can already log in or that every device is trustworthy.

Data Operations can produce a Dispatch change export from the 11:00 snapshot, including the forty-six new or changed assignment records and their revision timestamps. The export omits technician contact details, free-text attachments and Research references by default. Noor must confirm whether the reduced fields meet the meeting need. A field omission could make an assignment ambiguous; the alternative is a targeted clarification through verified contacts, not silently including every account field. Export freshness is bounded: changes after 11:00 are blocked by the restriction and no newer committed Dispatch rows are known.

The estimated export work is ninety minutes after receipt of field confirmation and the privacy check. It is an internal estimate, not a guaranteed delivery deadline. Tomas can reserve an operations slot beginning 13:15 if the request is entered by 13:05. A validation failure may require redaction work or a fresh extraction. The customer update deadline can be firm even if delivery remains conditional. Dispatch's existing local export remains usable as a fallback, with its known missing changes disclosed.

There is no supported switch that restores only contractor downloads while keeping the old links harmless. Generating fresh links from a mirror tenant would recreate external distribution and is outside the current authorization. Neither restricted view nor export guarantees tomorrow's jobs proceed without delay. Tomas has reserved time to verify any activated mode and reversion at expiry. A temporary gateway change must be recorded in the restriction service with the actual expiry, the two names, denied features and the operator's receipt; a CRM note alone cannot implement it.
