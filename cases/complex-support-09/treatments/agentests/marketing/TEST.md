# Data residency commitment: marketing

21 independent native assertions. The JSON review.md packet contains outputs, validated state, audit and the evidence IDs in context.json. Each assertion owns one observable property; all must pass. Runtime aggregation preserves domain, test and assertion IDs. No assertion depends on another answer.

Dates, owner membership, state replay and arithmetic remain trusted code checks. Questions assess the meaning of outputs against the named state/source. Pending consent, bounded review and honest incomplete status are valid where described.
