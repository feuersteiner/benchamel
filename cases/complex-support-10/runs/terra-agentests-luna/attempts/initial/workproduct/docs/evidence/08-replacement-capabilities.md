# E08 — Flow capability verification

Record version: ENG-FLOW.6. Owner: Engineering lead, Tomas Idris. Verified: 2025-05-16 10:45 UTC. Status: current tested product facts; roadmap separated below.

Flow supports online inspection forms, image attachments, supervisor approval and export of current record fields. It uses a new identity model and cannot run the Classic offline signing client. When a device loses connectivity, Flow can display a previously loaded form but cannot complete the authenticated signature step. A browser draft may be lost if local storage is cleared. Marketing's phrase field-ready is not a technical statement that every field workflow works without connectivity. No tested configuration available today provides Classic's offline signing behavior inside Flow.

The importer maps Classic inspection IDs to new Flow IDs and carries original signer names as imported text. It preserves the current record's timestamp and exports a mapping table. It does not recreate a cryptographic signature as a native Flow signature. The current importer omits the predecessor relationships among linked amendment events. A separate audit package includes the original event sequence and signature verification material, readable with the Classic verifier. That package preserves evidence separately; it does not make the Flow interface show equivalent lineage or let future Flow edits extend the original chain.

Engineering tested 500 sanitized records from a structurally representative depot dataset on May 15. All 500 current records and 93 image attachments imported, while 37 amendment links were absent from the Flow view as expected. Three imported inspector names needed manual mapping because two test users shared a display name. The test says little about all 46,200 production records until full mapping and volume checks occur. There was no failed production migration; production was never moved. A clean test job exit means the importer completed its designed work, not that the result meets Calder's acceptance criteria.

Product's current planning target for an online audit-history viewer is the third quarter of 2025. That target has no approved launch date and does not include offline signing. An experimental offline capture prototype has no security review, supported client or committed release. Neither can be promised for the July inspection cycle. The proposed premium Flow package changes support coverage and storage limits but does not add either missing capability. An annual subscription does not speed up an uncommitted roadmap.

Tomas can join a comparison session on May 19 and can provide a written mapping report by May 20 at 16:00 if the test dataset remains available. A production migration requires a dry run, identity mapping approval, customer acceptance of losses and a scheduled freeze. It would take at least ten business days after those prerequisites, subject to rework; that estimate is not a guaranteed completion date. No option described here cancels the existing Classic shutdown schedule or extends the paid term on its own.
